    BLACKWIRE / FIELD GUIDE

    Your Linux box lives in a tab.

    BLACKWIRE runs real Debian x86 programs in your browser using WebVM’s CheerpX engine. You don’t need a separate Linux computer.

    1. 01
      Boot Debian

      The engine loads from Leaning Technologies, and verified Debian disk blocks stream from this site as needed. First boot can take a little while.

    2. 02
      Use Wisp for internet

      Debian connects to wss://anura.pro/ at boot. No Tailscale account or exit node is needed. Change the relay or protocol in Network.

    3. 03
      Choose your shell

      The USER control above the terminal switches to a root shell without a password. Switching a running session restarts Debian and keeps its disk.

    Windows exit node instructions
    The browser has no physical Wi-Fi adapter. Wisp and Tailscale supply network access; neither exposes your Wi-Fi radio. Your VM disk is stored locally; clearing site data erases it.
